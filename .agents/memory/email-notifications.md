# Email Notification System

## Templates (artifacts/api-server/src/utils/emailSender.ts)
Five templates, all dark/Netflix-branded:
1. **Welcome** — first sign-in, hero gradient + "Start Watching" CTA
2. **OTP** — individual digit boxes, cyan accents, red expiry warning
3. **Login Notification** — security alert, device/time/IP table, optional "Continue Watching" poster image, "Was this you?" buttons
4. **Goodbye** — fired on logout, watchlist-saved reassurance, "Sign Back In" CTA
5. **Daily Featured** — cron-driven, shows user's last-watched poster (Firestore) or TMDB trending fallback

## API Endpoints (artifacts/api-server/src/routes/auth.ts)
- `POST /api/auth/welcome-email` — { email, displayName? }
- `POST /api/auth/send-otp` — { email, otp (4-8 digits), expiryMinutes? }
- `POST /api/auth/login-notification` — { email, deviceName?, platform?, posterUrl?, movieTitle? }
- `POST /api/auth/logout-notification` — { email, displayName? }

## Mobile Triggers (artifacts/s-movie/lib/emailTriggers.ts)
- `triggerWelcomeEmail` — called from ProfileContext on first sign-in (creationTime === lastSignInTime)
- `triggerLoginNotification` — called from ProfileContext on every returning sign-in
- `triggerLogoutEmail` — called from profile.tsx handleGoogleSignOut before firebaseSignOut
- `triggerOtpEmail` — called wherever OTP is generated by the caller

## Cron Job (artifacts/api-server/src/cron.ts)
- Schedule: `0 10 * * *` (10:00 AM UTC daily), overrideable via `DAILY_EMAIL_CRON` env var
- Started in `src/index.ts` inside the app.listen callback
- Fetches all Firebase Auth users via Admin SDK, queries each user's Firestore `user_progress` (most recent by `lastWatchedAtMs`), uses TMDB trending as fallback

## Required Secrets
- `EMAIL_USER`, `EMAIL_PASS` — Gmail address + App Password (already set)
- `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY` — Firebase service account for cron + Firestore queries
- `APP_URL` — optional; "Start Watching" and security links default to https://s-movie.replit.app
- `DAILY_EMAIL_CRON` — optional cron override (default: "0 10 * * *")

**Why:** Firebase Admin credentials are needed server-side because the cron reads user emails from Firebase Auth (admin.auth().listUsers()) and watch progress from Firestore. Without them the cron warns and skips — auth flow emails still work.
